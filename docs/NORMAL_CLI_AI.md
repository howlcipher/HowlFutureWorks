# Using a Normal CLI AI

Any competent CLI coding agent can maintain this repo. Start it in the repository root and tell it to read `AGENTS.md`.

For a narrow task, name the target Bot/role and let `context.yaml` control which files are loaded.

Examples:

- "Read AGENTS.md. Validate the org repo and repair configuration/schema errors only."
- "Read AGENTS.md and the R&D Bot context. Improve the R&D experiment templates without changing authority."
- "Read AGENTS.md. Reconcile live Grok Bots against desired state following docs/RECONCILE_ORG.md."

The durable instructions are in the repo; the command can stay short.
