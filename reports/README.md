# Reports

Generated management summaries. Reports are not the work queue or authorization system. Prefer links/IDs/hashes over copied raw transcripts.

Suggested categories:
- `daily/`, `weekly/`, `monthly/` — operating health;
- `audits/` — desired/deployed drift and control verification;
- `retrospectives/` — lessons after meaningful work;
- `workforce/` — staffing, succession and evidence-based workforce reviews.

Historical workforce attribution should point to immutable employee IDs from `workforce/`.
