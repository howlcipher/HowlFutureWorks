# Skills and Routines

Workflow: prove manually → document → save as skill → test → schedule/event-trigger as routine.

Routine definitions must include current input sources, stale/no-data behavior, approvals, partial-completion reporting and idempotent retry behavior.

Workforce management is split deliberately:
- position creation/retirement lives under Bot-factory skills,
- employee hire/separation/reassignment lives under workforce skills,
- handoff/context capture preserves institutional knowledge without retaining full chats.
