# Skill: Retire or Consolidate a Persistent Position

This skill changes organizational **positions**. It is not the procedure for firing an employee; use `automation/skills/separate-worker.md` for that.

1. Verify no durable need remains for the position.
2. Separate/reassign any current employee occupants through the workforce lifecycle.
3. Reassign active work, routines and ownership.
4. Preserve all workforce/contribution/handoff history.
5. Propose the position change in `bots/manifest.yaml` through review.
6. Reconcile deployed state and revoke obsolete access/routines.
7. Record an ADR/report when the organizational design materially changes.
