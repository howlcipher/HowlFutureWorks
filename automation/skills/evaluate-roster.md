# Skill: Evaluate the Bot Roster

Evaluate quarterly or when handoff/context overhead grows.

For each persistent Bot ask:
- Does it own a durable outcome?
- Does it need distinct context/tools/routines?
- Is its context being reused enough to justify persistence?
- Could an invoked specialist do the job more cheaply/cleanly?
- Are two Bots duplicating ownership?
- Does any Bot's context create dangerous privilege assumptions?

Produce keep / split / consolidate / deprecate recommendations. Do not apply authority-changing recommendations without review.
