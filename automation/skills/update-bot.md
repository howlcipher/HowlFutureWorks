# Skill: Update a Persistent Bot

1. Identify durable behavior that belongs in source-controlled configuration rather than a one-off message.
2. Change the smallest relevant file: instructions, context, capability, boundary, skill, or routine.
3. If authority changes, route through policy/approval review.
4. Validate and render the Bot bundle.
5. Compare with deployed state and reconcile permitted drift.
6. Record a concise audit report for meaningful changes.
