# Position Succession

Use for planned replacement, model/provider retirement, repeated evidence of poor fit, or continuity planning.

1. Identify position-critical knowledge and active work.
2. Produce/update the succession plan.
3. Capture predecessor curated context and contribution links; promote durable role lessons into `knowledge/positions/<position>.md`.
4. Hire replacement with a new employee ID unless this is an intentional rehire.
5. Run replacement onboarding/evals before broadening autonomy.
6. Transfer work and routines; never auto-transfer credentials.
7. Separate predecessor when ready.
8. Audit that current state points to the successor while historical attribution still points to the predecessor.
