# Reassign a Bot Employee

1. Freeze conflicting new assignments.
2. Capture current position work/handoff.
3. Verify the target position exists, has capacity, and its authority does not exceed approved policy.
4. Create a reassignment event with before/after positions.
5. Update roster, manager and context packet.
6. Reconcile deployed instructions/tools without copying obsolete context blindly.
7. Verify old position work has a new owner and new-position gates pass.
