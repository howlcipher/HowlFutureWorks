# Recovery

## Trigger
System/workflow is contained and ready to return to service.

## Procedure
1. Identify known-good desired state and authoritative work state.
2. Restore only required components/capabilities.
3. Validate policy, approvals, credentials and dependency state.
4. Run smoke/acceptance/security checks appropriate to the failure.
5. Resume routines gradually.
6. Monitor for recurrence and close only after evidence-backed verification.

## Required record
Link work item/incident, actors or employee IDs, timestamps, policy/risk context, evidence pointers, actions, verification and follow-ups.

## Exit criteria
- Recovered state is verified and corrective work is tracked.
