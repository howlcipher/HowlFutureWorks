# Security Incident

## Trigger
Suspected compromise, privilege misuse, prompt/tool injection with impact, data exposure, or control bypass.

## Procedure
1. Contain affected workers/routines/systems.
2. Preserve evidence and authoritative state.
3. Revoke/rotate compromised access.
4. Determine scope and affected data/systems.
5. Keep suspected agents from modifying their own evidence.
6. Recover from known-good state and add regression tests/policy changes.
7. Document incident and postmortem; escalate critical impact to Owner.

## Required record
Link work item/incident, actors or employee IDs, timestamps, policy/risk context, evidence pointers, actions, verification and follow-ups.

## Exit criteria
- Containment, recovery, verification and follow-up ownership are complete.
